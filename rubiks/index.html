Rubiks Cube Simulator

Home > Projects > Rubik's Cube Simulator

Interactive 3x3 Rubik's Cube built with Three.js and WebGL. Drag any sticker to twist that layer (the drag direction determines the turn), orbit around it freely, and use Scramble/Solve buttons to watch it shuffle and undo itself. It's a self-contained HTML file with no build step or backend, ported from an earlier Python/OpenGL desktop version of the same simulator.
